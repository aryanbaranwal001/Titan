# Proto Files

This directory contains `.proto` files that define the block data structures streamed from the Firehose endpoint (gRPC server) to the indexer (gRPC client).

Each .proto file’s local path and source are listed below.

| Local File | Source |
|------------|--------|
| `sf/ethereum/type/v2/type.proto` | [type.proto](https://github.com/streamingfast/firehose-ethereum/blob/develop/proto/sf/ethereum/type/v2/type.proto)|
| `sf/firehose/v2/firehose.proto` | [firehose.proto](https://buf.build/streamingfast/firehose/file/main:sf/firehose/v2/firehose.proto) |
